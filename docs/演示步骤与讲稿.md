# Go-win 第一阶段演示步骤与讲稿

按下面的顺序录制约 **3 分 45 秒**。录制前打开仓库目录和终端，并确认浏览器允许本地文件下载。命令行和浏览器可分别使用两个终端窗口。

## 0:00–0:25　开场与运行

**操作**　在仓库目录运行 `python3 -m gowin`，停留在显示操作提示的界面。

**口播**　大家好，这次展示的是 Go-win 棋类对战平台。平台支持两名玩家在同一台电脑上进行五子棋或围棋对战，棋盘边长可在 8 到 19 之间选择。命令行和浏览器界面共用同一套规则和存档。

## 0:25–1:05　命令行与输入校验

**操作**　逐条输入以下命令。尺寸错误和重复落子各停留一两秒，方便看清反馈。

```text
new gomoku 7
new gomoku 8
hints off
play A1
play A1
undo
hints on
quit
```

**口播**　边长 7 超出范围，系统提示重新输入。改为 8 后，黑方先下到 A1，白方再次选择同一位置时会收到占用提示。非法输入不会消耗回合。悔棋撤销 A1 的黑棋，行棋权回到黑方。操作提示可以随时关闭和打开。

## 1:05–2:10　围棋提子与存档

**操作**

1. 在终端运行 `python3 -m gowin --gui`。在浏览器选择「围棋」，边长填 **8**，点击「开始新局」。
2. 依次点击 **B1 → A1 → A2**。再点击一次 **A1**，展示禁入提示。
3. 点击「悔棋」，停留片刻展示恢复的白棋。再依次点 **A2 → H8 → D4**。
4. 点击「保存局面」。点击「重新开始」看到空棋盘，再点「读取存档」，从浏览器下载目录选择刚才导出的 `go-win-go.gowin.json`。如果浏览器给文件添加了编号，选择最新一份。

**口播**　现在演示围棋。白方下在 A1 后只剩 A2 一口气，黑方占据 A2，系统提掉白棋。白方此时下回 A1 会形成无气棋块，系统拒绝。悔棋同时恢复白棋、提子数和行棋方。继续走到第五步后，我把棋局保存为 JSON。重开会清盘，读回存档后，第五步的棋子、行棋方和剩余悔棋次数都恢复了。

## 2:10–2:40　围棋面积计分

**操作**　接着上一步恢复的局面，点击两次「虚着」。第一次显示白方虚着，第二次显示黑方虚着和比赛结果。

**口播**　恢复后的局面由白方先虚着，随后黑方也虚着。双方连续虚着触发面积计分。左上角的 A1 空点只接触黑棋，因此黑方三枚棋子加这个空点得到四分。其余大空区同时接触黑白双方，不计入任何一方。白方一分加七点五贴目，共八点五分，白方获胜。

## 2:40–3:20　五子棋终局与认负

**操作**　切换到「五子棋」，边长保持 **8**，点击「开始新局」。依次落子 **A1 → A2 → B1 → B2 → C1 → C2 → D1 → D2 → E1**。结果出现后重新开一盘五子棋，点击「认负」。

**口播**　五子棋同样由双方交替落子。黑方最后落在 E1，第一行连成五子，系统立即判黑方获胜。再开一局，黑方选择认负时，白方立即获胜。

## 3:20–3:45　设计与测试

**操作**　切换到设计文档的 UML 图，最后在终端运行 `python3 -m unittest discover -s tests -v`，停留在 `Ran 12 tests` 和 `OK`。

**口播**　后端把共通的回合和悔棋放在对局类里，把五子棋判线和围棋提子封装为独立的规则策略。命令行通过建造者组合棋盘、状态和提示。存档读取用同一套规则重放历史，校验通过后才替换当前对局。测试覆盖了五子棋平局、围棋劫争和异常存档。演示到这里，谢谢。
