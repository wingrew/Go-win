# Go-win 棋类对战平台

Go-win 支持同一台电脑上的双人围棋和五子棋。两种棋的棋盘边长都可设为 8 至 19。命令行和图形界面使用同一套对局后端，存档可以互读。

## 运行

需要 Python 3.9 或更新版本。进入仓库目录执行以下命令。

```sh
python3 -m gowin                # 命令行
python3 -m gowin --gui          # 本机浏览器图形界面
python3 -m unittest discover -s tests -v
```

Windows 上也可使用 `py -3` 运行。图形界面仅监听本机地址。若浏览器没有自动打开，可复制终端显示的网址访问。使用 `Ctrl+C` 停止图形界面服务。

## 命令行

| 命令 | 行为 |
| --- | --- |
| `new go 9` / `new gomoku 15` | 空闲时或终局后选择棋种和边长开局 |
| `restart` | 对局中沿用当前棋种和尺寸重开 |
| `play B2` | 在 B 列、第 2 行落子 |
| `pass` | 当前行棋方虚着，仅围棋可用 |
| `undo` | 撤销最近一次落子、虚着或认负，双方合用每局 3 次 |
| `resign` | 当前行棋方认负 |
| `save "round 1.gowin.json"` | 保存当前对局，文件名可含空格 |
| `load "round 1.gowin.json"` | 验证存档后覆盖当前对局 |
| `hints off` / `hints on` / `help` | 隐藏或恢复操作提示 |
| `quit` | 退出 |

坐标从左到右为 A 至 S，从上到下为 1 至 19，实际范围随棋盘尺寸变化。命令行以 `X` 表示黑棋，`O` 表示白棋。图形界面用鼠标点击交叉点落子，存档经浏览器下载和文件选择器导入。

## 对局规则

- **五子棋**采用自由规则。横、竖或斜向连续至少五枚同色棋子即获胜。若最后一手成线，优先判胜。棋盘占满且双方均未成线时判为平局。
- **围棋**按上下左右连通关系判断气和提子，禁止自杀和重现历史棋盘。双方连续虚着，或双方均无合法落点时，系统对终局盘面直接按面积计分。每方得分为留在盘上的己方棋子数加仅邻接己方棋子的空区点数，白方贴 7.5 点。虚着前可以通过继续行棋提出对方的死子。[Tromp–Taylor 面积计分](https://tromp.github.io/go.html)。
- 黑方先行。悔棋会恢复行棋方、被提棋子、连续虚着次数和终局状态。成功读取存档会恢复棋种、尺寸、对局历史及已用悔棋次数。
